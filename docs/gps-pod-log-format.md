# GPS 포드 로그 형식 (v1)

조끼 포드가 저장하고 앱이 읽는 파일 형식입니다. 펌웨어(`hardware/gps-pod`)와 파서(`lib/gps/parse.ts`)가 이 문서를 기준으로 맞춰져 있습니다.

## 파일

- 텍스트 CSV, UTF-8, 줄바꿈 `\n`(앱은 `\r\n`도 읽음)
- 파일 이름: `log_YYYYMMDD_HHMMSS.csv` (기록 시작 시각, UTC)
- 90분 경기 10Hz 기준 약 4MB. 앱에 올릴 때는 브라우저가 gzip으로 줄여서 보내 약 1MB가 됩니다.

## 구조

```
# gps-pod-log v1
# device=POD-01
# rate_hz=10
# fw=0.1.0
# gnss=m10
utc_ms,lat,lon,gspeed,heading,hacc,sacc,fix,nsv,batt_mv,temp_c
1792890123500,37.5000000,127.0000000,2.500,90.0,1.20,0.09,3,14,3900,31.5
...
```

- `#`으로 시작하는 줄은 메타데이터(`# 키=값`)입니다. 앱은 `device`, `rate_hz`만 씁니다.
- 첫 번째 일반 줄은 컬럼 이름입니다. **컬럼은 이름으로 찾기 때문에** 순서가 바뀌거나 컬럼이 추가되어도 읽을 수 있습니다.

## 컬럼

| 컬럼 | 단위 | 설명 | 앱이 쓰는 방식 |
|---|---|---|---|
| `utc_ms` | ms | UTC 시각(에포크 밀리초). GNSS 시간이라 선수 간 시계가 자동으로 맞음 | 필수 |
| `lat`, `lon` | 도 | WGS84 위도·경도 | 필수 |
| `gspeed` | m/s | 지상 속도(도플러). 위치 차분보다 정확해서 이동거리·스프린트 계산에 쓴다 | 비면 위치 변화로 대신 계산 |
| `heading` | 도 | 진행 방향 | 현재는 쓰지 않음 |
| `hacc` | m | 기기가 추정한 수평 오차 | 8m 초과 행은 버림 |
| `sacc` | m/s | 속도 오차 추정 | 현재는 쓰지 않음 |
| `fix` | - | 3 = 3D 위치 고정 | 3 미만 행은 버림 |
| `nsv` | 개 | 사용 중인 위성 수 | 기록용 |
| `batt_mv` | mV | 배터리 전압 | 기록용 |
| `temp_c` | ℃ | 배터리 표면 온도 | 기록용 |

## GPX도 올릴 수 있어요

스마트폰·시계 앱에서 내보낸 `.gpx`는 `<trkpt>`의 위치와 `<time>`을 읽습니다. 속도 태그가 없으면 위치 변화로 속도를 구하고, 1Hz 로그는 위치 평활화를 건너뜁니다. 10Hz 포드 로그보다 정확도가 낮습니다.

## 분석 기준 (lib/gps/analyze.ts의 `THRESHOLDS`)

| 항목 | 값 |
|---|---|
| 속도 구간 | 걷기 <2 · 조깅 2–4 · 달리기 4–5.5 · 고강도 5.5–7 · 스프린트 ≥7 m/s(25.2km/h) |
| 스프린트 | 7m/s 이상이 1초 이상 지속 |
| 가속/감속 이벤트 | ±2.5m/s²가 0.5초 이상 지속 |
| 정지 판정 | 0.3m/s 미만은 정지(GPS 떨림이 거리로 쌓이지 않게) |
| 끊김 | 2초 넘게 끊긴 구간은 거리와 시간에서 제외 |
| 튀는 점 | 12m/s 초과는 제외 |

## 구장 보정

구장 네 모서리의 위경도를 한 번 등록합니다. 1번이 원점, 1→2번이 길이(골라인에서 골라인), 1→4번이 폭 방향입니다. 등록하지 않으면 선수 한 명의 궤적에서 구장 범위를 추정하는데, 선수마다 틀이 달라져서 팀 평균 위치 같은 비교에는 쓸 수 없습니다.
